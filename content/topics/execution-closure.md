# 실행·개입·완결

계획된 과업이 어떻게 실제 수행이 되며, 언제 완료·중단·대체되었다고 판정할 수 있는지를 연구합니다. 시작과 활동량보다 새로운 방식의 정착, 예외와 우회, 실패 복구와 완결 증거에 주목합니다.

## 세부 연구주제

- implementation practices와 실제 수행
- 새로운 시스템과 업무방식의 채택·정착·루틴화
- 예외, 범위변경, 우회와 비공식 작업
- 지연·왜곡·재작업에 대한 intervention과 repair
- 완료, 중단, 철회, 대체와 실효 상태의 구분
- 로컬 과업 완료와 전략적 closure의 불일치
- 완결을 승인하거나 다시 여는 증거와 권한

주요 이론적 기반은 Strategy Implementation, Organizational Routines, Strategy-as-Practice와 Process Research입니다.
