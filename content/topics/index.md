# 연구 주제 지도

김민조 연구노트는 하나의 질문을 중심에 둡니다.

> 조직의 의도는 어떻게 공동의 실행으로 전환되는가?

이 질문을 전략의 선택부터 실행 이후의 학습까지 일곱 과정으로 나눕니다. 각 과정은 별개의 이론이 아니라, 하나의 판단이 조직을 통과하며 무엇으로 바뀌는지를 살피는 연구영역입니다.

```text
전략의도와 Commitment
→ 의미 번역과 과업분해
→ 권한·역할·책임 배분
→ 인계·상호의존성·조정
→ 실행·개입·완결
→ 관리통제·성과·책임귀속
→ 피드백·학습·재구성
```

## 다섯 횡단 렌즈

같은 실행과정도 누가 수행하는지, 어떤 조직과 경계조건에서 일어나는지에 따라 달라집니다.

| 렌즈 | 살펴보는 범위 |
|---|---|
| 행위자 구조 | 사람, 팀, 조직, AI Assistant, AI Agent, 자동화, Human-AI Hybrid System |
| 조직 맥락 | 중소·중견기업, 제조기업, 성장, 중앙집권, 승계, 변화과부하 |
| 조직 밖의 경계 | 고객, 사용자, 구매자, 공급자, 협력사, 전문가, 네트워크 |
| 정보와 증거 | 회의, 계획서, 일정표, 재고, 대시보드, 원가·성과자료, 업무로그 |
| 경계조건 | 상호의존성, 불확실성, 자원희소성, 시간압력, 위험도, 가역성, 인과모호성 |

AI는 별도의 유행 주제로 떼어 놓지 않습니다. AI가 의사결정과 실행의 행위자로 들어올 때 일곱 과정의 권한, 조정, 통제와 책임이 어떻게 달라지는지를 연구합니다.

이 지도는 현재 연구범위를 보여주는 작업 지도입니다. 새로운 이론이나 독립된 학문영역이 확정되었다는 뜻은 아닙니다.
